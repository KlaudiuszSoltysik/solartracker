# cron-jobs/downtime-checking/main.py

This script is designed to monitor and alert on downtime issues for assets managed by the SolarTracker platform. It uses PostgreSQL for database management and MongoDB for asset data storage.

## Files Content

- **File: `cron-jobs/downtime-checking/main.py`**
  - **Imports**: 
    - `logging`: For logging purposes.
    - `os`: For interacting with environment variables.
    - `datetime`: For handling dates and times.
    - `timedelta`: For calculating time differences.
    - `timezone`: For timezone conversions.
    - `psycopg2`: For database operations using PostgreSQL.
    - `requests`: For making HTTP requests to the Expo API for notifications.
  - **Functions**:
    - `get_mongo_assets()`: Retrieves a list of MongoDB assets from the specified host, port, username, password, and database name.
    - `send_expo_push_notification(device_id, reason)`: Sends an Expo push notification to the specified device ID with a message indicating downtime issues.
  - **Main Function**:
    - `main()`: Initializes the script by fetching MongoDB assets, checking for downtime issues, and sending notifications. It handles database connections, error handling, and logging.
