# ESP32 Simulator

This is a Python script designed to simulate an ESP32 device connected to a MQTT broker for communication purposes.

## Files Content

- **services/esp32-simulator/main.py**
  - This file contains the main function of the simulation.
  - It initializes the MQTT client, subscribes to the telemetry topic, and publishes commands to the controls topic.
  - The `on_connect` method is called when the connection with the broker is established.
  - The `on_disconnect` method is called when the connection with the broker is lost.
  - The `on_message` method handles incoming messages from the MQTT broker.

## Files Content

- **services/esp32-simulator/__init__.py**
  - This file contains the setup and configuration for the ESP32 simulator module.
  - It sets up the necessary environment variables, including the MQTT broker URL, port, username, password, and device ID.
