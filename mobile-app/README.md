# SolarTracker - A Personal Energy Tracker

SolarTracker is a personal energy tracker designed to help users manage their solar panel usage and monitor their energy consumption. It provides features such as:

- **Energy Tracking**: Users can track their daily, weekly, monthly, and yearly energy consumption.
- **Notifications**: Receive notifications for alerts like power outages or maintenance reminders.
- **Personalization**: Customize the display of data to suit individual preferences.

## Features

- **Data Collection**: Collects real-time solar panel usage data from various sources.
- **Energy Consumption Tracking**: Monitor daily, weekly, monthly, and yearly energy consumption.
- **Notifications**: Receive alerts for power outages or maintenance reminders.
- **Personalization**: Customize the display of data to suit individual preferences.

## Installation

To install SolarTracker, follow these steps:

1. Install Expo CLI globally:
   ```sh
   npm install -g expo-cli
   ```

2. Clone this repository and navigate into the project directory:
   ```sh
   cd solartracker
   ```
3. Initialize a new Expo project:
   ```sh
   expo init solartracker
   cd solartracker
   ```

## Usage

### Prerequisites

- **Node.js**: Ensure Node.js is installed on your system.
- **Expo CLI**: Install and initialize the Expo CLI globally.

### Installation

1. Clone this repository:
   ```sh
   git clone https://github.com/yourusername/solartracker.git
   cd solartracker
   ```

2. Initialize a new Expo project:
   ```sh
   expo init solartracker
   cd solartracker
   ```

3. Install the required dependencies:
   ```sh
   npm install
   ```

### Development

1. Build and run the development server:
   ```sh
   npm start
   ```

2. Open your browser to `http://localhost:3000/`.
